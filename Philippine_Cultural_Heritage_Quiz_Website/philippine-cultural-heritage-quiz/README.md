# Philippine Cultural Heritage Quiz

A responsive, static HTML/CSS/JavaScript quiz with 18 regional questions.

## Run locally
Open `index.html` in a modern browser.

## Deploy to Vercel
1. Create a GitHub repository.
2. Upload `index.html` (and this README).
3. Import the repository in Vercel.
4. Choose **Other** as the framework preset if prompted.
5. Leave the build command and output directory blank/default, then deploy.

The project is static and does not need a build step.

## MIT App Inventor WebViewer
Deploy the site to Vercel, then set the WebViewer's `HomeUrl` to the deployed HTTPS URL.
Enable JavaScript if your WebViewer component provides that setting. Sound requires a user tap
and browser audio support.

## Notes
All 18 question prompts, choices, answer keys, and feedback messages are transcribed from the
provided quiz PDF. The Region I question wording is retained as it appears in that source.
